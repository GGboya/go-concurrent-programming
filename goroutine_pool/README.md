# 简易协程池

## 背景
小美有几千万的追求者，每天都有大量的追求者向她表白。
但是小美每天只能和100个人聊天，所以她需要一个协程池来处理这些追求者。

小明也是小美的追求者，为了解决小美的麻烦，小明决定帮助小美实现一个协程池。但是小明也不会，你可以帮帮可怜的小明吗？

## 要求
实现一个简易的协程池，要求：
1、协程池的大小为 100，最多可以同时执行 100 个任务
2、提供一个接口，可以向协程池中添加任务
3、协程池中的协程自动执行用户提交的任务，如果协程数量达到上限，则等待有协程空闲后再执行

## 思路
想象当用户提交任务之后，这个任务的生命周期
任务提交前：
1、创建协程池，设置协程池大小，并启动协程池
2、异步监听是否有任务提交到协程池中。如果有任务提交，则获取一个 worker 来执行任务
3、执行完毕，将 worker 放回协程池。
这里我们用 cahnne 来存储 worker 和 task。 

任务提交后：
实现提交任务的接口，将任务提交到协程池中，这里可以将任务提交到 taskQueue 中，也用 channel 来实现

捋一下我们大概需要的数据结构
1、workerChan 用来存储 worker
2、taskQueue 用来存储 task
3、task 用来存储任务的执行方法，任务 ID
4、worker 用来记录 worker ID, worker 要实现 Run 方法，来执行任务
